# 최종 실기기 검증 — 0.2.0 후보

자동 확인이 불가능했던 항목만 모았습니다. **별도 테스트 폴더를 사용하세요.** 실패하면 기기/OS·동작 순서·화면 오류를 기록하고 중요한 폴더에 동기화를 켜지 마세요.

## 설치와 실제 화면

- [ ] Windows 설치/실행, 배율 100%·150%에서 기기 트리·버튼·동기화 창 사용
- [ ] Android release APK 설치, 알림·폴더 권한, 파일 저장, 뒤로가기·화면 회전
- [ ] Windows 재설치/업데이트 후 페어링·공유·동기화 설정·이전 버전 유지
- [ ] Windows 제거 시 데이터 보존 선택 후 원본/설정 유지. 데이터 삭제 선택은 이전 버전까지 지우므로 테스트 데이터로만 확인

## LAN 발견과 인증

- [ ] 유선 PC↔Wi-Fi PC, 유선 PC↔Android가 같은 공유기에서 서로 발견됨
- [ ] SAS 양쪽 승인 후 탐색. 거절·2분 대기·페어링 해제 후 접근 거부
- [ ] Wi-Fi 끊기/재연결·절전 복귀 후 다시 접속
- [ ] 읽기 전용·스트리밍 전용·기기별 차단·공유 중지가 상대 기기에 적용됨

## 파일·플레이어·3기기

- [ ] 실제 MP3/MP4 외부 재생, 중간/후반 seek, 원본 파일 변경 없음
- [ ] JPEG/PNG/WebP 썸네일·원본 보기, 사진 수정 후 다시 열기 갱신
- [ ] PC↔PC·PC↔Android 양방향 8 MiB 초과 복사, SHA-256 일치, 기존 이름 파일 보존
- [ ] 큰 파일 전송 중 연결을 끊고 동일 작업 재시도 시 정상 완료
- [ ] 3대가 있으면 A가 B→C 복사를 지시하고 C에 파일 도착. 필요한 기기끼리 모두 페어링하고 권한 설정

## 선택 동기화와 복구

- [ ] Windows에서 PC↔PC·PC↔Android 테스트 규칙 설정, 생성·수정·삭제가 설정한 방향으로 반영됨
- [ ] 오프라인 양쪽 수정 후 재접속하면 두 내용 모두 충돌 사본으로 보존됨
- [ ] 교체/삭제 전 버전 복원. 동기화에 등록하지 않은 일반 공유는 변경되지 않음
- [ ] 실제 Android 선택 폴더에서 큰 파일 교체·복원, 폴더 권한 철회 시 변경 중단

## 백그라운드와 장시간 사용

- [ ] Windows 창 닫기 후 접근 유지, 전체 종료 후 중단, 로그인 자동 시작
- [ ] Android 화면 끄기/절전 후 재생·복사·동기화 지속. 제조사 제한이 있다면 배터리 설정을 조정하고 재검증
- [ ] 평소 파일 규모로 수 시간 사용하며 저장 공간·응답성·재연결 확인

서버/외부망 Relay 검증은 필요 없습니다. Android 동기화 규칙은 Windows Agent가 구동합니다. 이 개발 환경에서는 WPF 실제 화면 자동화 접근이 거부되어 화면 QA를 완료하지 못했습니다.
